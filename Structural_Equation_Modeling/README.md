# Structural Equation Modeling

## Overview

This project presents the two model specifications explicitly identified as proposed models in the original analysis. The first uses latent organizational and interpersonal counterproductive-work-behaviour factors; the second models five observed CWB dimensions and their covariances.

## Methods

- Latent-variable measurement models
- Structural regression paths
- Bootstrap standard errors
- Standardized estimates and R-squared values
- Path diagrams and model comparison

## Data

The original `cwbper2023.csv` dataset is confidential and is not included.
