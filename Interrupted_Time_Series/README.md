# Time-Trend Regression with Newey-West Standard Errors

## Overview

This project preserves the original analysis of systolic blood pressure, diastolic blood pressure, and heart rate over time. Separate linear trends are estimated for treatment and control conditions, with Newey-West standard errors used for robust inference.

## Methods

- Linear regression by condition
- Newey-West heteroskedasticity-and-autocorrelation-consistent standard errors
- Aggregation by trial and condition
- Trend visualization

## Data

The original `JIS_copy.csv` dataset is not included because it is private.
