# Moderation and Moderated Mediation

## Overview

This project presents selected original PROCESS specifications examining competition, job insecurity, honesty-humility, conscientiousness, and counterproductive work behaviour.

## Methods

- PROCESS Model 2 moderation
- PROCESS Model 15 moderated mediation
- Covariate adjustment
- Bootstrap confidence intervals
- Interaction probing and plots

## Important note

The Andrew F. Hayes PROCESS implementation is not redistributed. The official R version must be obtained and activated separately. Only the author's model calls are shown.

## Data

The private `cwbminorcomps.csv` dataset is not included.
