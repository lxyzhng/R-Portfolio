# Latent Growth Curve Modeling

## Overview

This project preserves the original sequence of unconditional, correlated-residual, and conditional latent growth models across four measurement occasions.

## Methods

- Latent intercept and slope factors
- Fixed linear time scores
- Adjacent residual covariances
- Time-invariant predictor of intercept and slope
- Robust maximum-likelihood estimation

## Data

The original `MandFMonitoring.csv` dataset is not included.
